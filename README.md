
# Simon Says Game 🎮

A simple memory game built using HTML, CSS, and JavaScript.

## Features

- Random color sequence generated each round.
- Click buttons in the correct sequence to move to the next level.
- Track current score and high score.

## How to Play

1. Press any key to start the game.
2. Follow the color sequence shown by the game.
3. If you make a mistake, the game ends and your score is displayed.

## Tech Stack

- HTML
- CSS
- JavaScript
